STALKER Crafting Rework

КУДА КИДАТЬ
1. Создай папку плагина, например:
   gamemodes/ixhl2rp/plugins/stalker_crafting_rework/
2. Скопируй туда файлы из этого архива с сохранением структуры папок.
3. Убедись, что старый крафт-плагин отключён, иначе будут конфликты.

ВАЖНО
- Этот плагин рассчитан как замена старому crafting / better crafting.
- Не оставляй активными оба старых крафт-плагина одновременно.

ЧТО ВНУТРИ
- Новый крафт без tools
- 3 станции: полевая печь, химлаборатория, верстак
- Проверка навыка и изученного рецепта
- Русский интерфейс
- Тестовый рецепт: мясной пирог из мяса кабана
- Новый ингредиент: чеснок
- Пример записки для изучаемых рецептов

КОМАНДЫ
/craftrecipe <название>
/craftlearn <персонаж> <recipe_id>
/craftforget <персонаж> <recipe_id>

ТЕСТ
1. Заспавни станцию ix_station_field_stove
2. Выдай себе meat_boar, food_baton, garlic
3. Подойди к станции
4. Открой вкладку крафта и собери пирог

ЗАМЕЧАНИЕ ПО ПРЕДМЕТАМ
- meat_boar ожидается из файла вида sh_meat_boar.lua
- food_baton ожидается из файла батона
- если у тебя uniqueID у предметов отличается, поправь его в recipes/sh_boar_pie.lua
